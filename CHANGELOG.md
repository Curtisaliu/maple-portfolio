# Changelog

All notable changes to this portfolio will be documented here.

## [1.5.0] - 2026-11-12

### Added

- Added Certifications / Medals page with AWS, Genesys, and other certification sections
- Added Certifications link to the navigation bar
- Added EXP percentage next to the EXP bar

### Changed

- Level and EXP bar are now calculated from the current date instead of being hardcoded
- Switched fonts to Fredoka for headings and Nunito for body text
- Configured static export for hosting on Amazon S3 and CloudFront
- Upgraded Next.js to 16.4.6, including security fixes
- Updated README with deployment details and project structure

### Fixed

- Fixed active-page highlighting in the navigation bar when using trailing-slash URLs
